# Homepage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the China2Ghana Motors homepage — Hero, Trust layer (Source/Verify/Ship/Deliver), a restrained scroll-reveal Journey timeline, and a final CTA band — replacing the Foundation sub-project's placeholder `app/page.tsx`.

**Architecture:** Four focused section components under `components/home/`, each consumed by `app/page.tsx` in sequence. Trust layer and Journey share one small client-side scroll-reveal hook rather than duplicating `IntersectionObserver` wiring. No new dependencies — everything is built from the design tokens, shadcn primitives, and Lucide icons already in place from Foundation.

**Tech Stack:** Next.js 15.5.24 (App Router), TypeScript strict, Tailwind v4, shadcn/ui (Radix), Lucide, npm — all already established, unchanged by this plan.

## Global Constraints

(Copied from `docs/superpowers/specs/2026-08-31-homepage-design.md`, approved 2026-08-31, and the design tokens Foundation already established in `app/globals.css`.)

- No new dependencies. No animation library beyond plain CSS transitions driven by React state — the existing `--motion-base` duration (250ms) and `--motion-ease` curve (`cubic-bezier(0.22, 1, 0.36, 1)`) are the only motion values used.
- Reveal animation is a single pattern reused everywhere it's needed: fade (`opacity-0` → `opacity-100`) + small upward translate (`translate-y-4` → `translate-y-0`), triggered once via `IntersectionObserver` when ~20% of the element is visible, never repeated. `prefers-reduced-motion` is already handled at the CSS token layer (durations collapse to near-zero) — no per-component reduced-motion logic needed.
- Type scale tokens available as Tailwind utilities: `text-display` (56px/1.1), `text-h1` (40px/1.15), `text-h2` (30px/1.2), `text-h3` (24px/1.3), `text-body` (16px/1.6), `text-small` (14px/1.5), `text-label` (14px/1.4), `text-caption` (12px/1.4). Use these, not ad-hoc `text-3xl`/`text-2xl`/etc.
- Color tokens available: `background`, `foreground`, `primary`/`primary-foreground`, `accent`/`accent-foreground`, `muted`/`muted-foreground`, `border`, `card`/`card-foreground`. `accent` (controlled red) is used sparingly — icon accents only on this page, never as a background wash. `primary` (navy) is used as a full-bleed background exactly once, in the final CTA band.
- No vehicle cards. No fabricated stats, testimonials, certifications, or reviews anywhere in copy.
- `/vehicles` is linked from the Hero's secondary CTA even though the route doesn't exist yet (Marketplace sub-project). It will 404 until that sub-project ships — this is expected, not a defect to work around in this plan.
- No automated test framework (same reasoning as Foundation: this page has no real business logic, just presentational sections and one small, visually-verifiable reveal hook). Verification is `tsc --noEmit` / `next lint` / `next build` passing, plus a dev-server render check — same substitute-verification approach Foundation used successfully when no browser DevTools tool is available (HTTP fetch of rendered HTML + compiled CSS inspection).
- Responsive breakpoints to verify: 320 / 375 / 390 / 430 / 768 / 1024 / 1280 / 1440 / 1920px.

### Task 1: Scroll-reveal hook

**Files:**
- Create: `lib/hooks/use-reveal-on-scroll.ts`

**Interfaces:**
- Produces: `useRevealOnScroll<T extends HTMLElement>(): { ref: RefObject<T | null>; isVisible: boolean }` from `@/lib/hooks/use-reveal-on-scroll` — Tasks 3 and 4 both import and use this.

- [ ] **Step 1: Create the hook**

```ts
"use client";

import { useEffect, useRef, useState } from "react";

export function useRevealOnScroll<T extends HTMLElement>() {
  const ref = useRef<T | null>(null);
  const [isVisible, setIsVisible] = useState(false);

  useEffect(() => {
    const node = ref.current;
    if (!node) return;

    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          setIsVisible(true);
          observer.unobserve(node);
        }
      },
      { threshold: 0.2 }
    );

    observer.observe(node);
    return () => observer.disconnect();
  }, []);

  return { ref, isVisible };
}
```

"use client";

import { Compass, ShieldCheck, Ship, PackageCheck } from "lucide-react";
import { useRevealOnScroll } from "@/lib/hooks/use-reveal-on-scroll";
import { cn } from "@/lib/utils";

const stages = [
  {
    icon: Compass,
    title: "Source",
    copy: "We identify the right vehicle from verified suppliers in China, based on your specifications and budget.",
  },
  {
    icon: ShieldCheck,
    title: "Verify",
    copy: "Every vehicle is inspected and its condition confirmed before you approve the purchase.",
  },
  {
    icon: Ship,
    title: "Ship",
    copy: "We coordinate shipping and handle customs and clearing, so the process is never on you alone.",
  },
  {
    icon: PackageCheck,
    title: "Deliver",
    copy: "Your vehicle is delivered to you in Ghana, with updates and documentation the whole way.",
  },
];

function TrustCard({ icon: Icon, title, copy }: (typeof stages)[number]) {
  const { ref, isVisible } = useRevealOnScroll<HTMLDivElement>();
  return (
    <div
      ref={ref}
      className={cn(
        "rounded-lg border border-border bg-card p-6 shadow-sm transition-all duration-[var(--motion-base)] ease-[var(--motion-ease)]",
        isVisible ? "translate-y-0 opacity-100" : "translate-y-4 opacity-0"
      )}
    >
      <Icon className="h-8 w-8 text-accent" aria-hidden="true" />
      <h3 className="mt-4 text-h3 font-semibold text-foreground">{title}</h3>
      <p className="mt-2 text-small text-muted-foreground">{copy}</p>
    </div>
  );
}

export function TrustLayer() {
  return (
    <section className="mx-auto max-w-7xl px-4 py-20 sm:px-6 lg:px-8">
      <div className="grid grid-cols-1 gap-6 sm:grid-cols-2 lg:grid-cols-4">
        {stages.map((stage) => (
          <TrustCard key={stage.title} {...stage} />
        ))}
      </div>
    </section>
  );
}
